# Changelog

## 0.2.0 — 2026-09-16

First public release of this direct-mode variant; experimental compatibility status.

- Reconciled the standalone MK.2 bridge and weekly-usage gauge into one source tree.
- Added portable per-user install, diagnostic and uninstall commands.
- Corrected app targeting to the Codex bundle and guarded shortcuts against activation failure and focus loss.
- Added German/English command presets and configurable command titles.
- Fixed partial rollout-event parsing; reduced repeated history scans while preserving periodic reconciliation.
- Updated vulnerable dependencies and expanded synthetic regression coverage.
- Added English/German setup, privacy, compatibility and contribution documentation.
